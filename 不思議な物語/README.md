# 不思議な物語への招待状

星新一のショートショートや、「世にも奇妙な物語」「ミステリーゾーン」のようなどんでん返しの名作を参考にした、縦型ショート動画シリーズです。
どの動画も 1080×1920・30fps・約1分です。ナレーション、BGM、効果音（ステレオ）が入っています。

| 話 | ファイル | タイトル | 表現 | オチ |
|---|---|---|---|---|
| 1 | `01-reply.mp4` | 返信 | チャット画面 | 3年間の既読無視が「人類の代表」だった |
| 2 | `02-shadow.mp4` | 一日先の影 | シルエット劇 | 明日の二人は喧嘩中。今日手をつなぐと、影も仲直りした |
| 3 | `03-time-shop.mp4` | 時間買い取ります | 文字と数字 | 買い取った時間を使って、店主は312歳 |
| 4 | `04-report.mp4` | 第三惑星調査報告 | 報告書とシルエット | その報告書もまた、板で書かれていた |
| 5 | `05-three-minutes-1.mp4` | 三分後の自分（前編） | チャット画面・ホラー | 「三分後、俺は死ぬ」 |
| 6 | `06-three-minutes-2.mp4` | 三分後の自分（後編） | チャット画面・ホラー | 命を救ったのは、自分がついた嘘だった |
| 7 | `07-substitute.mp4` | 身代わり | オフィスと家の二画面 | 身代わりの身代わりとして出社し、家ではロボットが寝ている |

## 素材について
- **ナレーション**：VOICEVOX（全員 1.2 倍速。`lib/series.js` の `VV_RATE` で変更可）。全行の読みをカナで確認済みです。
  | 役 | VOICEVOX の話者 |
  |---|---|
  | 語り手 | 青山龍星（しっとり） |
  | 宇宙人（1話・4話） | Voidoll（機械音声に加工） |
  | 店主（3話） | 雀松朱司 |
  | 主人公・三分後の自分（5・6話） | 白上虎太郎（ふつう／びくびく。三分後の自分は電話越しに加工） |
  | 警察官（6話） | 四国めたん（電話越しに加工） |
  | 身代わりロボット（7話） | ナースロボ＿タイプＴ |

  **公開するときは、動画の説明欄に使った話者をクレジットしてください。** 例:
  ```
  VOICEVOX:青山龍星, VOICEVOX:Voidoll, VOICEVOX:雀松朱司, VOICEVOX:白上虎太郎, VOICEVOX:四国めたん, VOICEVOX:ナースロボ＿タイプＴ
  ```
  キャラクターごとに利用規約があります（営利利用の条件などは各キャラクターの規約を確認してください）。
- **BGM・効果音**：すべてプログラムで作曲・合成したオリジナルです。外部の音源は使っていません。
- **フォント**：しっぽり明朝、Noto Sans JP（SIL Open Font License）。

## 作り直すとき
```sh
npm install
pip install pyopenjtalk-plus imageio-ffmpeg
bash scripts/setup-voicevox.sh        # VOICEVOX エンジンを入れて起動（初回のみダウンロード）
node scripts/render.mjs stories/01-reply --out 不思議な物語   # 1話だけ
node scripts/render.mjs stories/01-reply --yomi                    # 読みの確認だけ
```
台本（ナレーション、読み、タイミング）は `stories/<話>/index.html` の先頭にまとまっています。
