# ショートショート台本集（初稿）

> 星新一のショートショートを参考にした、1話完結の短い物語6本。
> どれも40〜60秒・縦型。形式は無理に混ぜず、**その話に一番合う表現を1つ（多くても2つ）** だけ使う。

## 共通の考え方

### 星新一らしさとして取り入れたこと
- **アイデアは1話に1つだけ**。設定を説明しすぎない。
- **登場人物に固有名詞をつけない**。「エヌ氏」「博士」「男」など。誰にでも当てはまる話になる。
- **時代や場所を特定しない**。何年たっても古くならない。
- **最後の一行で、それまでの意味がひっくり返る**。怖い話でも、どこか皮肉やユーモアが残る。
- **説明ではなく、状況の変化で見せる**。セリフは少なく、ナレーションは短い文で。

### 満足感を出すための型（全話共通）
| 段階 | 尺の目安 | やること |
|---|---|---|
| 設定 | 0–8秒 | 奇妙な状況を1つだけ提示する（最初の1秒で「え？」と思わせる） |
| 展開 | 8–35秒 | その状況がエスカレートする（3段階で強めていく） |
| 転 | 35–50秒 | 前提が揺らぐ |
| オチ | 最後の5〜10秒 | 1行で意味がひっくり返る。**その後に余計な説明を入れない** |

### シリーズとしての見せ方
- 1話完結のアンソロジーにする（例：『30秒の奇妙な話』）。どの話から見ても楽しめる。
- 毎回、冒頭に同じタイトルロゴと同じ語り口（明朝体の文字＋短い文）を入れて、シリーズとして覚えてもらう。
- 形式は話ごとに変わってもよいが、**色数を絞る、明朝体、ナレーションの文体**でシリーズの統一感を出す。

## 第1話「返信」（45秒）
**形式**：💬 チャット画面だけ
**アイデア**：3年間、知らない番号から毎朝「おはよう」だけが届き続ける。

| 時間 | 画面 | テキスト | 音 |
|---|---|---|---|
| 0–3 | 知らない番号からのトーク画面。一番上に「おはよう」 | 🔤「知らない番号から、毎朝『おはよう』が届く。」 | 通知音 |
| 3–12 | 画面が高速でスクロールする。日付だけが変わり、「おはよう」が何百個も並ぶ。**すべて既読、返信なし** | 1日目… 100日目… 365日目… 1000日目 | 通知音が速くなっていく |
| 12–18 | 1001日目。届かない | 🔤「ある朝、届かなかった。」 | 無音 |
| 18–24 | 1002日目、1003日目。やはり届かない。エヌ氏が入力しかけては消す | 🔤「気づけば、待っていた。」 | 時計の音 |
| 24–30 | エヌ氏が初めて送信する | エヌ氏「おはよう」 | 送信音 |
| 30–40 | 相手の入力中…が長く続いたあと、長文が届く | 「こちらは地球外通信実験です。応答までの所要時間：1002日。」「結論：この星に知的生命体がいる可能性は低い。」「調査を終了します。」 | 通知音 |
| 40–45 | エヌ氏があわてて送る | エヌ氏「ちょっと待って」 → **既読がつかない** | 無音 → 暗転 |

**オチ**：最後まで「既読」がつかない。3年間、既読だけつけて返事をしなかったのは、エヌ氏のほうだった。
**画像生成**：なし（チャット画面だけで完結する）。
**制作メモ**：試作1のチャット画面をそのまま使える。一番作りやすい。

## 第2話「一日先の影」（55秒）
**形式**：👤 シルエット劇（＋🔤 短いナレーション）
**アイデア**：男の影が、一日だけ先の未来を歩くようになる。

| 時間 | 画面 | テキスト | 音 |
|---|---|---|---|
| 0–5 | 夕方の道。男のシルエットと、足元から伸びる影。影だけがわずかに遅れて動く | 🔤「ある日、影がずれた。」 | 足音 |
| 5–15 | 日が変わるごとにずれが大きくなる。やがて影は、男と違う動きをするようになる。**影が転ぶと、翌日、男も同じ場所で転ぶ** | 🔤「影は、明日の自分だった。」 | |
| 15–25 | 男は影を見て、雨の日に傘を持っていく、落ちてくる植木鉢をよける。便利に使い始める | 🔤「便利なものだった。」 | 小さな成功の効果音×2 |
| 25–35 | ある夕方、影が駅のホームで**誰かと抱き合う**。相手の影の形は見えるが、誰なのかはわからない | 🔤「明日、7時42分。」 | オルゴール |
| 35–45 | 翌日、男はホームで待つ。誰も来ない。隣には、同じように落ち着かない様子で足元を見ている女性が1人いる | 🔤「誰も来ない。」 | 電車の到着音 |
| 45–52 | 2人が同時に顔を上げる。女性の足元にも**ずれた影**。2人の影は、昨日の時点ですでに抱き合っている | 🔤「——あなたも？」 | 無音 |
| 52–55 | 本体の2人が照れくさそうに並ぶ。影は先にさっさと手をつないで歩いていく | 🔤「影のほうが、せっかちだった。」 | オルゴール |

**オチ**：未来を見て待っていた2人は、実はお互いの影に導かれていた。怖い設定が、やさしい恋の話で終わる。
**画像生成**：夕方の道、駅のホームの背景（人物なし）。人物と影はコードで描く。
**制作メモ**：影を人物と別の動きで描くのは、シルエット劇の強みそのもの。

## 第3話「時間買い取ります」（55秒）
**形式**：🔤 文字演出（＋数字のインフォグラフィック）
**アイデア**：退屈な時間を、お金で買い取ってくれる店。

| 時間 | 画面 | テキスト | 音 |
|---|---|---|---|
| 0–5 | 黒い画面に看板の文字が浮かぶ | 「時間、買い取ります。」 | ベルの音 |
| 5–15 | エヌ氏が売る時間のリストと値段が並ぶ。売った時間は、エヌ氏の人生から消えて一瞬で過ぎる | 「通勤　1時間　1,000円」「待ち時間　30分　500円」「会議　2時間　3,000円」 | レジの音 |
| 15–25 | 売る項目がエスカレートする。人生のタイムライン（横棒）から灰色の部分が消えていき、残りがどんどん短くなる。お金のカウンターは増えていく | 「風邪で寝込む日　1日　5万円」「失恋の夜　1晩　10万円」「老後　20年　10億円」 | カウンターが回る音 |
| 25–32 | タイムラインが一瞬で最後まで進む。エヌ氏は大金持ちで、そしてもう老人 | 🔤「楽しいことだけの人生は、あっという間だった。」 | 風の音 |
| 32–42 | 老人になったエヌ氏が「買い戻し」の値札を見る | 「退屈な時間　1時間　1億円」 | 衝撃音（小） |
| 42–50 | 店の奥で、店主がお茶を飲みながら、ただぼんやり窓の外を眺めている | 店主「ええ、高いですよ。ほかでは手に入りませんから」 | 時計の音だけ |
| 50–55 | 店主の手元に、買い取った「退屈」の帳簿が山になっている | 店主「私は毎日、これをゆっくり味わっているんです。」 | 暗転 |

**オチ**：いちばん価値があったのは、捨てた「退屈な時間」だった。店主はそれを買い集めて、一番ぜいたくな暮らしをしていた。
**画像生成**：古い時計店風の店の中（人物なし）。人物は出さず、手元やシルエットだけで見せる。
**制作メモ**：数字、横棒、カウンターの動きは、モーショングラフィックが最も得意な表現。

## 第4話「角のない国」（50秒）
**形式**：🔷 図形キャラ（絵本風）
**アイデア**：「ぶつかると痛いから」と、王様が国じゅうの角を禁止する。

| 時間 | 画面 | テキスト | 音 |
|---|---|---|---|
| 0–5 | 四角い家、四角い人、四角い王様が並ぶ国 | 「しかくの国の王様は、角にぶつかって足の指をけがした。」 | |
| 5–10 | 王様がおふれを出す | 「角を禁止する。」 | ラッパの音 |
| 10–22 | 国じゅうで角を削る。家も人も机も、どんどん丸くなる。住民は「やさしい国になった」と笑う | | 削る音、明るいBGM |
| 22–35 | 丸くなったものは止まっていられない。家が転がり、人が転がり、王様の城も転がる。国じゅうが坂を下っていく | | 転がる音が重なっていく |
| 35–43 | 坂の下は海。すべてがそこへ向かっている。ただ1つ、角を削るのを忘れていた、古くて頑固な**四角い箱**だけが坂の途中に残っている | | BGMが止まる |
| 43–48 | 転がってきた丸い国民と王様が、箱にぶつかって次々に止まる。箱の後ろに、国がまるごと積み重なる | 「どすん。」 | 衝撃音×何回か |
| 48–50 | 箱の上に王冠が乗る | 「その国では、今でも角が一つだけ大切にされている。」 | ファンファーレ（小さく） |

**オチ**：嫌われていた「角」が、最後に国を救う。子どもにも伝わる寓話。
**画像生成**：絵本の紙の質感と、坂や海のクレヨン背景（キャラはコード）。
**制作メモ**：試作3の図形キャラ、転がる動き、衝突の演出をほぼそのまま使える。

## 第5話「最適化」（50秒）
**形式**：アプリの画面UI＋🔷 図形（インフォグラフィック）
**アイデア**：人生を自動で効率化するアプリ。

| 時間 | 画面 | テキスト | 音 |
|---|---|---|---|
| 0–5 | アプリの起動画面。エヌ氏の1日が大小の円（泡）で表示される：睡眠、仕事、通勤、雑談、散歩、猫、寄り道、昼寝… | 「あなたの人生を最適化します。」 | 起動音 |
| 5–20 | 「無駄」と判定された泡が次々に割れて消える。寄り道、雑談、昼寝、散歩…。右上の「効率」メーターが上がっていく | 「寄り道：削除」「雑談：削除」「昼寝：削除」 | 泡が割れる音 |
| 20–28 | 最後に残った「猫」の泡が点滅する | 「猫：非効率。削除しますか？」 | 警告音 |
| 28–33 | エヌ氏の指が「はい」の上で止まる。それでも押す | | 泡が割れる音（大きく） |
| 33–40 | 効率メーターが 100% になる。画面の下に、ずっと隠れていた**2本目のメーター**が現れる：「幸福度 0%」 | 「最適化が完了しました。」 | 無音 |
| 40–46 | アプリが分析する | 「原因を特定しました。削除した項目はすべて、あなたが笑っていた時間でした。」 | |
| 46–50 | 割れた泡がすべて逆再生で戻る。最後にアプリのアイコン自体が泡になって割れる | 「最後の無駄を削除します：本アプリ」 | 泡が割れる音 → 猫の鳴き声 |

**オチ**：効率化のアプリが最後に削除したのは、自分自身だった。
**画像生成**：なし（UIと図形だけで完結する）。
**制作メモ**：UI、円、メーターの動きだけで作れるので、量産しやすい。

## 第6話「第三惑星調査報告」（55秒）
**形式**：🔤 報告書風の文字演出＋👤 人間のシルエット
**アイデア**：宇宙人が地球を観察し、「支配者は光る板（スマホ）だ」と結論づける。

| 時間 | 画面 | テキスト | 音 |
|---|---|---|---|
| 0–5 | 報告書のような文字がタイプされる | 「第三惑星　調査報告書」 | タイプ音 |
| 5–15 | 街を歩く人々のシルエット。全員がうつむいて、手の中の光る板を見ている | 「観察1：住民は一日中、光る板に頭を下げている。」 | タイプ音 |
| 15–22 | 夜、人々が板に線をつないでいる（充電） | 「観察2：夜になると、住民は板に食事を与える。」 | |
| 22–30 | 板が震えると、人々がいっせいに歩き出す、立ち止まる、笑う | 「観察3：板が鳴ると、住民は命令どおりに動く。」 | 通知音が大量に |
| 30–35 | 報告書に結論の判子が押される | 「結論：この星の支配者は、板である。」 | 判子の音 |
| 35–42 | 宇宙人が、すべての板に同時にあいさつを送る。世界中の画面に表示される | 「はじめまして。上を見てください。」 | 世界中で通知音 |
| 42–50 | 人々のシルエットが、いっせいに顔を上げて空を見る。夜空いっぱいの星 | | 無音 → 小さなオルゴール |
| 50–55 | 報告書に一文が追加される | 「追記：板の命令で、住民が初めて上を向いた。支配者であることを確認。」 | 判子の音 |

**オチ**：スマホが人間を支配しているという皮肉を、最後に「空を見上げる」という美しい絵で終わらせる。
**画像生成**：夜の都会の街並み、星空の背景（人物なし）。人物はシルエットで描く。
**制作メモ**：人々が同時に顔を上げるシーンが、この話の見せ場になる。

## 添削のときに見てほしいポイント
1. オチが読めてしまう話や、逆にわかりにくい話はないか。
2. 残したい話、捨てたい話。
3. 後味の好み：皮肉寄り（1・3・6）と、ほっこり寄り（2・4・5）のどちらを多くするか。
4. ナレーションの文体：今は短い常体（「〜だった。」）でそろえています。
