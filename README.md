# モーショングラフィック・ショートドラマ

## AIショートショート（1話完結シリーズ）

完成動画は [`AIショートショート/`](AIショートショート/) にあります。各話のソースは `stories/` です。

| # | タイトル | 表現 |
|---|---|---|
| 1 | 返信 | チャット画面 |
| 2 | 一日先の影 | シルエット劇 |
| 3 | 時間買い取ります | 文字と数字 |
| 4 | 第三惑星調査報告 | 報告書とシルエット |
| 5 | 三分後の自分（前編） | チャット画面・ホラー |
| 6 | 三分後の自分（後編） | チャット画面・ホラー |
| 7 | 身代わり | オフィスと家の二画面 |

```sh
pip install pyopenjtalk-plus imageio-ffmpeg   # ナレーションと書き出し
bash scripts/setup-voicevox.sh                 # VOICEVOX を入れて起動（あれば自動で使われる）
node scripts/render.mjs stories/01-reply --out AIショートショート
node scripts/render.mjs stories/01-reply --yomi   # ナレーションの読みだけ確認
```

- `lib/series.js` … シリーズ共通の字幕、ロゴ、エンドカード、話者ごとの声（VOICEVOX の話者名）の設定。
- `lib/chat.js` / `lib/threemin.js` … チャット画面と「三分後の自分」の演出部品。
- `scripts/tts.py` … ナレーション合成（VOICEVOX、なければ Open JTalk）。読みをカナで出力するので、読み間違いは台本側の読み（yomi）で直す。次のセリフに重なる行は少しだけ速く読む。
- `scripts/sfx.mjs` … ステレオの効果音・環境音（フィルタで合成）、BGM の自動作曲、声のエフェクト（機械音声・電話越し）、ナレーション中の音量下げ。

## 試作（4形式）

コードで描く縦型（1080×1920）ショートドラマの試作集です。4つの表現形式を1本ずつ作っています。

| # | 形式 | タイトル | ジャンル | 長さ |
|---|---|---|---|---|
| 01 | チャット画面ドラマ | 知らない番号 | サスペンス | 31秒 |
| 02 | シルエット劇 | 7時42分、3両目 | 恋愛 | 32秒 |
| 03 | 図形キャラ（セリフなし） | まる と しかく | コメディ／ほっこり | 27秒 |
| 04 | 文字が演技するドラマ | 「またね」の続き | 切ない／恋愛 | 31秒 |

## 使い方

```sh
npm install                          # フォントと Playwright
node scripts/render.mjs              # 全話を out/*.mp4 に書き出し
node scripts/render.mjs shorts/01-chat   # 1本だけ
node scripts/snap.mjs shorts/01-chat 1 5 10   # 指定秒のコマを並べた確認画像
```

- ブラウザで `shorts/<名前>/index.html` を開くとプレビュー再生できます（ローカルサーバー経由で開いてください。例: `npx serve .`）。
- 書き出しには ffmpeg（libx264）が必要です。無ければ `pip install imageio-ffmpeg` で自動的に使われます。

## 構成

- `lib/mg.js` … 最小のアニメーションエンジン。各話は `draw(ctx, t)` を1つ書くだけ。同じ `t` なら同じ絵になるので、プレビューと書き出しが一致します。
- `shorts/*/index.html` … 各話。先頭に脚本（セリフ・タイミング）がまとまっていて、ここを書き換えれば次の話が作れます。
- `scripts/render.mjs` … ヘッドレス Chromium で1フレームずつ描画し、ffmpeg で MP4 にします。
- `scripts/sfx.mjs` … 効果音・環境音を合成します（仮の音です。本番では BGM・ナレーションに差し替え推奨）。
