# モーショングラフィック・ショートドラマ試作

コードで描く縦型（1080×1920）ショートドラマの試作集です。4つの表現形式を1本ずつ作っています。

| # | 形式 | タイトル | ジャンル | 長さ |
|---|---|---|---|---|
| 01 | チャット画面ドラマ | 知らない番号 | サスペンス | 31秒 |
| 02 | シルエット劇 | 7時42分、3両目 | 恋愛 | 32秒 |
| 03 | 図形キャラ（セリフなし） | まる と しかく | コメディ／ほっこり | 27秒 |
| 04 | 文字が演技するドラマ | 「またね」の続き | 切ない／恋愛 | 31秒 |

## 使い方

```sh
npm install                          # フォントと Playwright
node scripts/render.mjs              # 全話を out/*.mp4 に書き出し
node scripts/render.mjs shorts/01-chat   # 1本だけ
node scripts/snap.mjs shorts/01-chat 1 5 10   # 指定秒のコマを並べた確認画像
```

- ブラウザで `shorts/<名前>/index.html` を開くとプレビュー再生できます（ローカルサーバー経由で開いてください。例: `npx serve .`）。
- 書き出しには ffmpeg（libx264）が必要です。無ければ `pip install imageio-ffmpeg` で自動的に使われます。

## 構成

- `lib/mg.js` … 最小のアニメーションエンジン。各話は `draw(ctx, t)` を1つ書くだけ。同じ `t` なら同じ絵になるので、プレビューと書き出しが一致します。
- `shorts/*/index.html` … 各話。先頭に脚本（セリフ・タイミング）がまとまっていて、ここを書き換えれば次の話が作れます。
- `scripts/render.mjs` … ヘッドレス Chromium で1フレームずつ描画し、ffmpeg で MP4 にします。
- `scripts/sfx.mjs` … 効果音・環境音を合成します（仮の音です。本番では BGM・ナレーションに差し替え推奨）。
